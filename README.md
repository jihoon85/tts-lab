# TTS Lab

[Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)로 여러 목소리를 만들어 보는 개인 실험용 웹 UI예요. Apple Silicon Mac(MPS)에서 동작을 확인했어요.

## 기능

- **목소리 디자인**: "낮고 거친 30대 남성"처럼 텍스트로 묘사해 새 목소리 만들기
- **프리셋 화자 + 톤**: Sohee, Ryan, Ono_Anna 등 프리셋 화자에 감정·톤 지시
- **보이스 클로닝**: 3~10초 참조 음성으로 목소리 복제
- **캐릭터**: 마음에 드는 결과를 캐릭터/감정별 참조 음성으로 저장하고, 같은 목소리로 대사 생성

## 실행

```bash
uv sync
uv run python app.py   # http://127.0.0.1:7860
```

- 첫 생성 때 모델(1.7B 기준 모델당 약 4GB)을 받아서 몇 분 걸려요.
- `TTS_SIZE=0.6B uv run python app.py`로 프리셋 화자·클로닝 모델을 작은 버전으로 바꿀 수 있어요. 목소리 디자인 모델은 1.7B만 있어요.
- 생성 결과는 `outputs/`, 캐릭터 참조 음성은 `characters/`에 저장되고 둘 다 git에는 올라가지 않아요.

## 주의

보이스 클로닝은 본인 목소리나 사용 동의를 받은 목소리로만 쓰세요.
